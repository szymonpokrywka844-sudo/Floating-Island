# Katalog na kod źródłowy i biblioteki C (`c_src`)

Tutaj trafiają natywne biblioteki C (.c, .h, .dll) do zadań wymagających maksymalnej wydajności lub niskopoziomowego API Windowsa:
- Przechwytywanie audio WASAPI i szybka transformata Fouriera (FFT).
- Hooki myszy i klawiatury (`SetWindowsHookEx`).
- Niskopoziomowy monitor zasobów systemowych.
